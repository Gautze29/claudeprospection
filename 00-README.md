# Librairie GTM Fondateur B2B — Claude Code Skills

14 skills exécutables pour piloter ton acquisition B2B seul avec Claude.
Sans SDR. Sans agence. Sans consultant GTM.

Construit par **Eithan Benero** — [Cold to Cash](https://www.cold-to-cash.com)

---

## Installation

1. Copie les fichiers `.md` dans `.claude/skills/` de ton projet
2. Tape `/nom-du-skill argument` dans Claude Code
3. Claude exécute le workflow complet — recherche, analyse, rédaction

Exemple : `/signaux-achat Marie Dupont Alma` → Claude recherche les signaux d'achat sur Marie Dupont chez Alma et retourne un brief avec score de priorité.

## Les 14 Skills

### Trouver et prioriser les bons prospects

| Skill | Invocation | Ce que Claude fait |
|-------|-----------|-------------------|
| [01 - Signaux d'Achat](01-signaux-achat.md) | `/signaux-achat <prénom-nom> <entreprise>` | Cherche les signaux (levée, recrutement, poste, contenu) et retourne score + fenêtre de timing |
| [02 - Timing d'Outreach](02-timing-outreach.md) | `/timing-outreach <liste-prospects>` | Calcule les fenêtres pour chaque signal et classe du plus urgent au moins urgent |
| [03 - ICP Scoring](03-icp-scoring.md) | `/icp-scoring <entreprise> <titre-contact>` | Score sur 100 selon 4 dimensions et retourne Tier A/B/C/D + recommandation |
| [04 - Sources de Personnalisation](04-seaux-personnalisation.md) | `/seaux-personnalisation <prénom-nom> <entreprise>` | Recherche les hooks de personnalisation (posts, profil, signaux) et les classe par impact |
